## 📘 Descripción del curso

Arquitectura de Software es el curso en el que se estudian las decisiones estructurales que definen cómo se organiza, relaciona y escala un sistema: capas, componentes, patrones arquitectónicos y modelos como C4 y UML. Desde la primera sesión se trabaja con un repositorio real, donde la estructura de carpetas, las ramas y los commits ya son evidencia de decisiones arquitectónicas, y donde el proyecto integrador evoluciona junto con su documentación durante todo el semestre.
